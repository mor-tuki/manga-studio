# 04 検収と入稿前のチェック表

## 絵（1ページずつ、画像を開いて目で見る）
1. **文字**：全部の吹き出しを1字ずつ台本と照合（誤字・脱字・増えた文字・頼んでいない書き文字）
2. **読む順**：コマの中は右→左。先に話す人が右・その吹き出しが右上
3. **キャラの目印**：髪型・髪飾り・服の柄が全コマで残っているか（例：AIニケちゃんは「AI」のヘアクリップ・ポニーテール・牛柄のパーカー＝水玉になっていたら直す）
4. **健全さ**：足の向き・座り方・胸もと
5. **オチが絵で分かるか**（セリフを隠しても伝わるか）
6. **マンガに見えるか**：マンガの文法7つ（`skills/01_name_with_codex.md`）。等分の箱が並んでいたら描き直し
7. **綴じ側**：顔とセリフが綴じ側15mmに入っていないか。見開きは右半分が先のページか

## 入稿（機械で確かめる項目）
- [ ] 3638×5102px ちょうど（グレー600dpi）／白黒2色なら 7276×10205px
- [ ] グレースケール（8bit）・アルファなし・背景白
- [ ] dpi の記録が 600（または 1200）
- [ ] ガイド線・目盛り・ページ番号・トンボが残っていない
- [ ] コマの絵が「無理な拡大」になっていない（拡大率の記録を見る）
- [ ] ファイル名が `001.png`… の連番で欠けがない・ページ数が台割と一致
- [ ] 「非公式のファンメイド作品」＋キャラ名の表示（必要な作品）
- [ ] P-H3 を使ったページが、海外に届く媒体（電子版・通販・SNS 告知）に載らないか
