# 02 ローカル生成（自分の PC で描く）

ComfyUI で描く。測った環境＝RTX 3050 6GB（ノート）・RAM 32GB。

## SDXL ＋ キャラ LoRA（本番の既定）
- 土台：Animagine XL 4.0（商用可）。キャラ LoRA を重ねる〔実測・2026-11-14〜15〕
- LoRA の強さ＝`strength_model 1.0`・`strength_clip 0`。形を大きく崩す絵（バトル）は 0.8 にするとプロンプトが効きやすい
- 🔴 Animagine の品質タグ（`masterpiece, high score, great score, absurdres`）を Illustrious 系の土台に入れると、絵の中に文字として描かれる
- 使える手〔実測・各1〜3枚〕
  | 手 | 一言 |
  |---|---|
  | 白黒ペン線 | バストアップ向き |
  | 高解像の描き直し（hires 1.5倍） | 全身の見せ場（1枚 約95秒） |
  | 顔だけ描き直す（FaceDetailer） | 全身の小さい顔のにごりが直る（3枚中3枚） |
  | 線を写す（ControlNet-LLLite canny） | 下絵でポーズを決める（2枚では保てた） |
- 効かなかった手：棒人間の pose／`chibi, dot eyes`／`high contrast`

## P-H3（参照画像つきのマンガ絵）
- ⚠️ **ライセンスの線を先に読む**（`docs/rights-and-characters.md`）。X・海外に届く媒体には使わない
- 必要なもの：本体 w4a8・テキストエンコーダー w4a8・VAE int8（配布元＝PrunaAI/P-H3-Image-Comfy）
- 🔴 ComfyUI は `--disable-fast-disk --disable-pinned-memory` を付けて起動（付けないと読み込み途中で Windows のエラー1450で落ちた〔実測・1回〕）
- 🔴 Load CLIP の type は `minimax`（違うと `mat1 and mat2 shapes` で落ちる）
- 時間（1024×1024・8ステップ）：参照なし21秒／参照1枚45秒／参照2枚80秒〔実測〕
- 効き〔実測〕：
  - キャラの立ち絵を参照に渡すと、白黒でも髪型・髪飾り・服の装飾まで出る
  - 種（seed）を固定して服だけ文で変えると、顔と髪はそのまま服だけ入れ替わる（4着とも）
  - 参照2枚で「服だけ2枚目から借りる」が効く。ただしカラーでは**文の言葉が参照の色に勝つ**（"cow-pattern" と書くと白×茶の牛柄になる）＝色は文で正しく書く
  - 服の文字は崩れる＝文字は写植で
- 🔴 本体（12GB 超）を読み込む瞬間にメモリが詰まる。重い作業と重ねない・描き終わったら止める
