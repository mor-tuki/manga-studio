# 原稿の決まり（冬コミ合同誌 2026）

主催の原稿案内と原稿テンプレートから。**最終的には主催の案内が正**です。

## 大きさ
- 仕上がり A5＝148×210mm。上下左右に塗り足し3mm＝**154×216mm** で書き出す
- 灰色の濃淡を使う原稿＝**グレースケール600dpi（約3638×5102px）**
- 白黒2色の原稿＝モノクロ2階調1200dpi（約7276×10205px）
- 原寸100％・背景は白・透過なし
- 🆕 **「背景は白」は本当に真っ白（255）にそろえる**（2026-11-19）：AI で描いた絵は、白に見える所も 235〜254 のノイズが全面に残っている（レベル補正を最大にすると見える）。書き出しの前に、明るさ一定以上（目安 235・試し刷りで決める）を 255 にそろえ、真っ白の割合を測って確かめる。線とトーンは残す。やり方（Pillow の数行）＝[手引き 3-3](manga-howto/03_production_assembly.md#3-3-白を真っ白にそろえる)
- 🔴 **小さい画像の dpi 表示だけを変える／無理に拡大する、はしない**。原寸で十分な細かさの絵にする（描き直しながら高解像にした絵は、仕上がりの線とトーンが原寸の画質ならよい）

## 安全域（テンプレートより）
- 文字・大事な絵は **上下・外側10mm、綴じ側15mm** より内側
- 綴じ側5mm（テンプレートの橙の帯）は製本で見えにくい＝特に注意
- 青い点線は文字配置の目安で、コマ枠ではない。背景は必要なら塗り足しまで描く
- ガイドは提出時に消す

## 右綴じ
- 漫画は右→左に読む。コマの中も、先に話す人・先の吹き出しが右
- **右ページの綴じ側は左、左ページの綴じ側は右**
- 見開きは「右ページ（先）＋左ページ（後）」。どのページが右になるかは台割で確認する

## 見開き
- 1枚の横長で描き、真ん中に左右3mmずつの塗り足しの重なりを持たせて2ページに割る（案・主催に確認）
- 顔とセリフは綴じ側15mmに入れない。1枚絵より「ノドをまたぐ横長コマ2〜3個」のほうが扱いやすい

## 書き出し
- 1ページずつ PNG・`001.png`、`002.png`…
- 作品ごとに ZIP。ZIP 名は主催の指定どおり（修正版は v02 と変更ページを連絡）
- メモに作品名・作者名・ページ数・表現色と解像度
