## 根拠ラベルの読み方

数字や「効いた」には、どこから来た話かを付けています。

| ラベル | 意味 |
|---|---|
| 〔実測〕 | うちで描いて、画像を開いて確かめた。分かるものには枚数や回数を添えています（「1枚」「1回」は、まだ1回しか試していないという意味です） |
| 〔実体験〕 | 描いて使ってみた感触。数えてはいない |
| 〔調査（一次）〕 | 公式資料・モデルカード・ライセンス原文などで確かめた |
| 〔調査（二次）〕 | 記事やまとめで読んだ。原文までは確かめていない |
| 〔他者の経験則〕 | 他の人の制作報告（出典つき） |
| 未検証 | 案だけで、まだ試していない |

画像生成は同じ頼み方でも毎回少しずつ違う絵が出ます。「1枚で効いた」は「たまたま」の可能性があるので、大事なページでは2〜3枚描いて選んでください。

## 先に守る線

- 全年齢・キャラクターの公式ガイドライン・モデルのライセンス＝[docs/rights-and-characters.md](../rights-and-characters.md)
- **AIニケちゃん**：公式の二次創作ガイドライン（https://nikechan.com/guidelines/derivative ）で、AI に渡してよい素材は「公式の三面図（二次創作用）・ロゴ・公式VRMモデル」だけです〔調査（一次）・2026-11-12／11-16 確認〕。配信のスクリーンショット・既存のイラスト・他の人のファンアートは使えません。
  - 公式で認められているのは、公式素材だけを使う場合までです。うちは生成した絵を素材・下絵にするので、ニケさんから個別に許可をもらいました。ほかのメンバーは各自で確認してください。
  - うち（ネクタリカ側）は、ニケさん個人から**うち宛ての許可**をもらって、ニケちゃんをローカル生成で描く・下絵や LoRA 学習に使う、をしています。これは**うちへの許可で、他のメンバーに同じ許可が出ているわけではありません**。ローカル生成・下絵・LoRA 学習にニケちゃんを使いたいときは、各自でニケさんに確認してください。
- 他の人の作品・配信の画像は、参照にも学習にも使わない。このリポジトリにも入れない。
- 他の人の二次創作（ファンアート・ファンメイドの設定など）は、この手引きでは使いません（うちの線）。
