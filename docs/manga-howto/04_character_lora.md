# 4. キャラ LoRA の作り方

SDXL の土台（Animagine XL 4.0）に、キャラの顔・髪型・衣装を覚えさせる LoRA を作る手順です。うちはこれまでに5本（ネクタリカ4本＝通常・別の土台・バトル・衣装違い／AIニケちゃん1本）作りました〔実測・2026-11-14〜19〕。

> うちの方針：**良い出力がたまってから学習する**。いまは Codex で良いページを描きためている段階です。

## 4-1. 素材に使ってよいもの

- 自分で描いた（生成した）絵と、キャラの権利者が AI 用に許している公式素材だけ。
- 🔴 **他の人の絵は入れない**（ファンアート・配信のスクリーンショット・サムネを含む）。
- 🔴 **P-H3（MiniMax H3）の出力は学習に使わない**（ライセンスで、出力をほかの AI の学習に使うことが禁止〔調査（一次）〕）。
- AIニケちゃんを素材にするには、公式ガイドラインの範囲と、作者のニケさんの許可が要ります。うちはうち宛ての許可をもらっていますが、**他のメンバーへの許可はニケさん次第**です（[README](README.md)「先に守る線」）。うちで学習したニケちゃんの LoRA は、ファイルも名前もこのリポジトリに入れていません（設定は各自の `local/engines.local.json`）。

## 4-2. 素材づくり（Codex で約30枚）

〔実測・Codex で約30枚×3本〕

1. **ショットの一覧を30通り**書く（立ち・アクション・顔のアップ・あおり・俯瞰・後ろ姿…）。1行＝1枚。
2. 画風の見本を `-i` の1枚目、キャラのデザイン参照を2枚目に渡して、1枚ずつ Codex で描く（[01](01_codex_one_page.md) 1-4）。キャラの説明（服の丈・襟の閉じ方まで）と画風の説明はファイルに分けて毎回同じものを使う。
3. **一覧画像にして全部を目で見る**。
   - 1回目の30枚は、胸もとに切り抜きのある衣装・膝丈のスカートに多くずれて、学習に使えなかった → キャラの説明に「胸もとは閉じたハイカラー・ふくらはぎ丈」と書き足して30枚を作り直した〔実測・1回〕
   - ずれた絵・後ろ姿のはずが正面になった絵などは外す（28枚に減らした回もある）
4. **白を掃除してから学習**する（明るさ 235 以上を 255 に・[03](03_production_assembly.md) 3-3）。掃除した素材で学習した LoRA は、出す絵の白の割合も高かった（真っ白の割合 32〜47%／掃除なし 8〜19%）〔実測・2本。構図の違う比べなので傾向まで〕。
5. ショットに「あおり・俯瞰・アクション」を入れておくと、**学ばせていない構図**（夜の屋上で跳ぶ・俯瞰でひざをつく）にも素直についた。立ち絵寄りの素材の LoRA より構図の追随がよかった〔実測・3構図×4段階〕。

- 🔴 素材を描くスクリプトが「いちばん新しい画像を写す」方式だと、別の Codex の作業と同時に走らせたときに取り違える（1枚すり替わった）〔実測・1回〕。素材づくりの間は他の Codex を走らせない。

## 4-3. キャプション

- 各画像に同じ名前の `.txt`。中身＝**識別語**（例 `your_character`）＋画風の語＋ショットの語（`low angle`・`action` など）。
- 最初の LoRA では、髪・瞳・髪飾りの語を**書かずに**学習した → 識別語だけで髪・瞳・髪飾りが出るようになった〔実測〕。書かなかったものを LoRA が覚える、という考え方。

## 4-4. 学習の設定（OneTrainer）

OneTrainer＝LoRA などを学習させる無料の道具（画面つき）。入手先＝https://github.com/Nerogar/OneTrainer

〔実測・RTX 3050 6GB・RAM 32GB〕

| 項目 | うちの値 |
|---|---|
| 種類 | SDXL LoRA・U-Net だけ |
| rank / alpha | 8 / 8 |
| 解像度・batch | 768・1 |
| 学習率 | 1e-4 |
| 精度 | U-Net の重み FLOAT_8・学習 FLOAT_16 |
| オプティマイザ | AdamW 8bit |
| ゆらぎ | 左右反転・切り抜きのゆらぎは無し |
| 長さ | 47〜50 epoch＝約1400〜1500 step・250 step ごとに保存 |

- 所要：約1.9秒/step・1500 step で約50分・VRAM 最大 約5.2GB。
- 🔴 **読み込みのとき RAM を一時的に 20GB 以上使う**。始める前に空きメモリを見る。AI エージェントの中で回すと、メモリ不足で止められたことがある〔実測・1回〕＝**別の窓で回す**。学習中は描く作業と重ねない。
- 新しい土台で学習するときは、設定の土台の名前・出力名・作業フォルダを分ける。土台のライセンスを先に一次情報で確かめる。

## 4-5. どの段階（step）を使うか

- 保存した段階ごとに、**LoRA なし／500／750／1000／(1250)／1500 × 構図3つ（学ばせていない構図を含む）× seed 2つ**の一覧を作って、人の目で選ぶ。
- うちの結果〔実測・各1本〕：
  - **500 step でデザインがそろった**（3本とも）
  - Illustrious XL で学習した1本は 1000 step から本人になった
  - 1500 step はアクションで頭（髪型）が崩れた（1本）＝長く学習すればよいわけではない
  - 長い棒の武器は 750 step から正しく描けた（1本）＝小物は少し遅れて覚える
  - いま使っている段階＝500〜750（うちの `local/engines.local.json`・Git 管理外）
- LoRA の強さは `strength_model 1.0`・`strength_clip 0`。形を大きく崩す絵は 0.8（[skills/02](../../skills/02_local_generation.md)）。

## 4-6. 土台との相性

- Animagine 用に学習した LoRA は Illustrious XL では効かない（髪の色がばらばら）〔実測〕。土台ごとに学習し直す。
- Animagine の品質タグを Illustrious 系に入れると、絵の中に文字として描かれる（skills/02）。
