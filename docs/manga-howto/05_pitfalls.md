## Codex（image_gen）

| 起きたこと | 対処 |
|---|---|
| `-s workspace-write` を付けても「ワークスペースが読み取り専用」で、指定した場所に保存できない（11/16 は17回とも・その後も続いている）〔実測〕 | 生成された画像は `~/.codex/generated_images/<セッション>/` に残っている。そのセッションのいちばん新しい PNG を写す。原因は未調査 |
| 「プロンプトのファイルを読んで」と頼むと、ファイルを読むコマンドが方針で拒否されて画像なしで終わる〔実測・1回〕 | プロンプトの中身を**標準入力で渡す**＋「Do NOT read any files」（[01](01_codex_one_page.md) 1-8） |
| 2本同時に走らせて利用上限に当たった〔実測・1回〕／同時に走らせた別の作業の画像を取り違えた〔実測・1回〕 | **Codex は並列で走らせない**。1本ずつ順番に |
| 手書きの文字（擬音）の後ろに、頼んでいない1字（「〜」や線）が増える〔実測・2件〕 | 検収で1字ずつ見る。短い音ほど崩れやすい印象（未確認） |
| 書き文字の「縦書き」の指定が守られず横書きで出る〔実測・1件〕 | 読めれば可。本番は写植 |
| 斜めのコマの角度が浅く出る（数字で頼んでも守られない）〔実測・2枚中2枚〕 | きつい斜めは手元で枠を切る案（未検証） |
| 「文字を描くな」の指定に巻きこまれて、文字の形の髪飾り（「AI」のヘアクリップ）がただの四角になる〔実測〕 | 「この文字だけは描いてよい・必須」と例外を書く（型 `prompt_page_bw.txt` の書き方） |
| 白黒の割り当て（柄が白丸か黒丸か・服の白黒）がコマをまたいで入れ替わる〔実測・1枚〕／小物の濃さがコマで変わる〔実測・1件〕 | キャラ欄に白黒の割り当てを書く（効くかは未検証） |
| 参照の衣装に胸もとの切れ込みがあると、「閉じた襟」と書いても残る〔実測・2枚〕 | 強めの一段落を毎回／閉じた衣装の参照を用意（01 1-3） |
| 頼んでいない小物が足される（袖の小さなリボン・空の雲など）〔実測・数件〕 | 害がなく全ページでそろっていれば残す。気になれば編集で |

## ComfyUI・ローカル生成

| 起きたこと | 対処 |
|---|---|
| 起動用の `.bat` で窓が消えて10分応答なし〔実測・1回〕 | python を直接起動（`-WorkingDirectory` 必須・[02](02_local_generation.md) 2-2）。待つ時間の上限を決めておく |
| 2人のコマや大きなモデルの読み込みで RAM が詰まり、AI エージェントが裏の処理（別の生成・見張り）を止めた〔実測・複数回〕 | 空き6GB未満なら描かない・1枚ずつ・描き終えたら止める。学習・重いモデルと重ねない |
| ComfyUI を止めるとき、関係のない別のアプリのプロセスまで止めた〔実測・1回〕 | コマンドラインに `ComfyUI\main.py` を含む python だけを止める。起動したときの PID を控えておく |
| P-H3 の読み込み途中に Windows のエラー1450で落ちる／`mat1 and mat2 shapes` で落ちる | 起動オプションと Load CLIP の type（[skills/02](../../skills/02_local_generation.md)） |
| Git Bash から Python にパスを渡すと、`/c/...` の形で保存に失敗した〔実測〕／カンマでつないだ2つ目のパスが変換されない〔実測〕 | パスは `C:/...` の形で書く |
| Illustrious 系に Animagine の品質タグを入れたら、絵の中に文字が描かれた〔実測〕 | 土台に合った品質タグにする |
| `lace` と書くと胸もとが透けたレースになる絵が出る（27枚中6枚ほど）〔実測〕 | `lace` を外すか、ネガティブに `see-through`（未検証）。閉じた絵だけ選ぶ |
| 全身＋白背景なのに背景に色がつく（3枚中3枚）〔実測〕 | 組むときに白黒化する（02 2-4） |
| 新しいノードの `install.py` が大きなモデルを自動で落とす（Impact-Pack） | 実行しない。必要なモデルだけ手で置く |
